# AI Product Builder Framework

A 9-step methodology I built and use for taking a product idea from raw problem to working prototype — Problem Identification → Problem Validation → Competitive Research → Spec in Markdown → Build Prototype → Internal Testing → User Feedback → Iterate → Develop.

I've presented this internally to my product team and packaged it as a shareable Claude skill so it's reusable step-by-step, not just a slide.

See [SKILL.md](./SKILL.md) for the full framework.

## Why I built this

Most product ideas fail from skipping validation, not from bad execution. This framework forces the unglamorous steps — proving the problem is real, checking what already exists — before any code gets written, so the build phase is spent on an idea worth building.

## Built with
